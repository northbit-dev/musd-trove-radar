    How to read this page

    ICR = collateral value ÷ debt for one trove; below 110 % it can be liquidated by anyone. TCR is the same ratio for the whole system; below 150 % Mezo enters Recovery Mode, where troves below 150 % can be liquidated too. The liquidation price is the BTC price at which a trove reaches 110 %. Every number is read from the MUSD contracts at one block (live in your browser, or the embedded snapshot if the RPC is unreachable) and can be re-derived with the open-source CLI.
